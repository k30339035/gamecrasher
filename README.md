# 🏗️ Building Destruction - 3D Game

최신 3D 기술을 활용한 **현대식 고층 건물 파괴 게임**입니다!

## ✨ 주요 기능

- **현실적인 현대식 건물**: 유리창, 콘크리트 외벽, 강철 프레임으로 구성된 실제 건축물 구조
- **10단계 레벨 시스템**: 1단계부터 10단계까지 점점 높아지는 고층 건물
- **실시간 물리 엔진**: Cannon-es를 사용한 실감나는 파괴 물리 시뮬레이션
- **PBR 렌더링**: 물리 기반 렌더링으로 사실적인 재질 표현
- **재질별 파티클 효과**:
  - 유리: 반짝이는 파편 효과
  - 콘크리트: 먼지와 파편 효과
  - 강철/금속: 스파크 효과
- **고급 조명**: 태양광, 채우기 조명, 하늘 반사광, 고품질 그림자
- **도시 환경**: 주변 건물들과 함께하는 도시 배경
- **터치/마우스 지원**: 모바일과 데스크톱 모두 지원
- **점수 시스템**: 블록을 파괴하면 점수 획득

## 🎮 게임 방법

1. 마우스나 터치로 건물의 블록을 클릭하세요
2. 클릭한 부분에 충격이 가해져 블록이 무너집니다
3. 모든 블록을 파괴하면 다음 레벨로 진행합니다
4. 10개의 레벨을 모두 클리어하세요!

## 🚀 실행 방법

### 1. 의존성 설치
```bash
npm install
```

### 2. 개발 서버 실행
```bash
npm run dev
```

브라우저가 자동으로 열리며 게임이 시작됩니다!

### 3. 프로덕션 빌드
```bash
npm run build
```

## 🛠️ 기술 스택

- **Three.js**: 최신 WebGL 기반 3D 렌더링
- **Cannon-es**: 물리 엔진 (ES6 모듈)
- **Vite**: 빠른 개발 서버 및 빌드 도구

## 🎯 레벨 진행

- **Level 1-2**: 3-4층 현대식 건물 (8x8m)
- **Level 3-4**: 5-6층 중층 건물 (12x12m)
- **Level 5-6**: 7-8층 고층 건물 (16x16m)
- **Level 7-8**: 9-10층 초고층 건물 (18x18m)
- **Level 9-10**: 11-12층 마천루 (20x20m)

## 🎨 기술적 특징

### 건물 구조
- **층별 바닥**: 콘크리트 재질의 슬래브
- **외벽**: 유리 커튼월 시스템
- **창틀**: 알루미늄 프레임
- **구조 기둥**: 강철 프레임 (코너 4개)
- **옥상**: 콘크리트 루프

### 렌더링
- **PBR 재질**: 물리 기반 렌더링
- **ACES Filmic Tone Mapping**: 영화 같은 색감
- **고품질 그림자**: 4K 해상도 섀도우 맵
- **환경 반사**: 큐브맵 기반 반사
- **부드러운 카메라**: 궤도 애니메이션

### 물리 시뮬레이션
- **재질별 질량**: 유리(0.5), 콘크리트(2.0), 강철(3.0)
- **마찰력과 반발력**: 현실적인 충돌 반응
- **중력 시뮬레이션**: 자연스러운 낙하
