# 🏗️ Building Destruction - 3D Game

최신 3D 기술을 활용한 건물 파괴 게임입니다!

## ✨ 주요 기능

- **10단계 레벨 시스템**: 1단계부터 10단계까지 점점 어려워지는 건물 구조
- **실시간 물리 엔진**: Cannon.js를 사용한 실감나는 물리 시뮬레이션
- **아름다운 3D 그래픽**: Three.js r160+ 최신 버전 사용
- **파티클 효과**: 블록 파괴 시 화려한 파티클 효과
- **터치/마우스 지원**: 모바일과 데스크톱 모두 지원
- **점수 시스템**: 블록을 파괴하면 점수 획득

## 🎮 게임 방법

1. 마우스나 터치로 건물의 블록을 클릭하세요
2. 클릭한 부분에 충격이 가해져 블록이 무너집니다
3. 모든 블록을 파괴하면 다음 레벨로 진행합니다
4. 10개의 레벨을 모두 클리어하세요!

## 🚀 실행 방법

### 1. 의존성 설치
```bash
npm install
```

### 2. 개발 서버 실행
```bash
npm run dev
```

브라우저가 자동으로 열리며 게임이 시작됩니다!

### 3. 프로덕션 빌드
```bash
npm run build
```

## 🛠️ 기술 스택

- **Three.js**: 최신 WebGL 기반 3D 렌더링
- **Cannon-es**: 물리 엔진 (ES6 모듈)
- **Vite**: 빠른 개발 서버 및 빌드 도구

## 📁 프로젝트 구조

```
building-destruction-game/
├── index.html              # 메인 HTML 파일
```

## 🎯 레벨 진행

- **Level 1-2**: 작은 건물, 기본 구조
- **Level 3-5**: 중간 크기 건물, 복잡한 구조
- **Level 6-8**: 큰 건물, 구멍이 있는 구조
- **Level 9-10**: 거대한 건물, 최고 난이도
